03Установка в Lampa

Lampa → Настройки → Расширения → Добавить плагин. Адрес сервера и токен уже вшиты в плагин.

Плагин не собран: выполните npm run build.

04Приложение Apple TV

Добавить подключение → Вручную → адрес ниже → «Определить и проверить».
